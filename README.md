# Ant & The Rain

This is a small top-down survival game I made in godot .In this game you can control an ant, dodge falling rain, collect crumbs, and shelter beneath leaves. The best survival time is saved locally.

## Play locally

Open `project.godot` in **Godot 4** and press **F5**.

- **Move:** WASD or arrow keys
- **Touch/mouse:** hold or drag to move the ant
- **Pause:** Esc

## Project structure

- `scenes/` – main scene, actors, UI, rain, and audio nodes
- `scripts/` – gameplay and UI logic
- `assets/sprites/` – pixel-art sprites
